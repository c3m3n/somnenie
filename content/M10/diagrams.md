# M10 — Схемы

## Диаграмма 1. Натрий и калий: цель vs. реальность

### Сравнение норм и типичного потребления

| Минерал | Цель (ВОЗ) | Типичное западное потребление | Соотношение |
|---------|-----------|------------------------------|-------------|
| **Натрий (Na)** | < 2 000 мг/день | 3 000–4 500 мг/день | 🔴 Превышение в 1,5–2× |
| **Калий (K)** | ≥ 3 510 мг/день | 2 000–3 000 мг/день (ниже нормы) | 🔴 Недостаток |

> **Результат дисбаланса:** хроническое высокое Na + низкое K → гипертония, риск инсульта и болезней почек.

### Где на самом деле прячется натрий

```
Солонка на столе        ~  5–10% потребления
Домашняя готовка        ~ 10–15%
──────────────────────────────────────────
Переработанные продукты ~ 75–80% ← ГЛАВНЫЙ источник
```

### Основные источники Na vs. K

| 🔴 Богаты натрием | 🟢 Богаты калием |
|-------------------|-----------------|
| Хлеб и выпечка | Картофель (печёный с кожей) |
| Мясная гастрономия (колбасы, ветчина) | Бананы, авокадо |
| Сыр | Томаты, шпинат, свёкла |
| Соусы, кетчуп, майонез | Бобовые (чечевица, фасоль) |
| Готовая еда / ресторан | Орехи и семена |
| Консервы | Молочные продукты |

### Пересчёт: соль → натрий

```
Соль (г) × 400 = Натрий (мг)
Пример: 5 г соли = 2 000 мг Na (суточный лимит ВОЗ)
```

## Диаграмма 2. Кальций: роли, источники, всасывание

### Распределение кальция в организме

```
┌─────────────────────────────────────────────┐
│  99% — кости и зубы (структурный резервуар) │
│   1% — ионы Ca²⁺ в крови и клетках         │
│         │                                   │
│    ┌────┴────────────────────────────┐      │
│    │ Сокращение мышц (в т.ч. сердце) │      │
│    │ Нервная передача сигналов        │      │
│    │ Свёртывание крови                │      │
│    │ Секреция гормонов                │      │
│    └─────────────────────────────────┘      │
└─────────────────────────────────────────────┘
```

### Биодоступность кальция из разных источников

| Источник | Усвоение | Примечание |
|----------|----------|-----------|
| Молоко, йогурт, сыр | ~30% | Стабильный источник |
| Обогащённые напитки (соя, овёс) | ~30% | Встряхивать перед употреблением |
| Тофу с сульфатом кальция | ~20–40% | Зависит от метода производства |
| Брокколи, кале, бок-чой | ~40–60% | Низкие оксалаты → хорошее всасывание |
| **Шпинат, мангольд** | **~5%** | ⚠️ Высокие оксалаты блокируют Ca |
| Бобовые | ~15–20% | Фитаты снижают усвоение |

> ⚠️ **Добавки в высоких дозах (>1000–1200 мг/день из добавок):** риск камней в почках, возможный риск для сердечно-сосудистой системы. UL: 2 000–2 500 мг/день (из всех источников). Предпочтительный путь — пища, не таблетки.

## Диаграмма 3. Магний, фосфор и главный дисбаланс западного питания

### Магний (Mg)

| Параметр | Мужчины | Женщины |
|----------|---------|---------|
| Норма (мг/день) | 400–420 | 310–320 |
| Роль | Кофактор >300 ферментов (синтез ДНК, энергетика, мышцы, нервы) ||
| Лучшие источники | Орехи (миндаль, кешью), семена (тыква), бобовые, цельные зёрна, листовая зелень ||
| Группы риска | ЖКТ-заболевания, алкоголизм, диуретики, ИПП, диабет 2 типа ||
| Избыток из добавок | Диарея (безопасный «сигнал» превышения) ||

### Фосфор (P)

| Параметр | Значение |
|----------|---------|
| Норма | 700 мг/день |
| Реальное потребление | Большинство людей превышают норму |
| Скрытый источник | Фосфатные добавки E338–E343 (газировка, переработанное мясо) — всасываются **лучше**, чем природный фосфор |
| Критическая группа | ХБП (хроническая болезнь почек): избыток фосфора → кальцификация сосудов |

### Главный дисбаланс западного питания

```
ИЗБЫТОК                          ДЕФИЦИТ
   │                                │
   ▼                                ▼
🔴 Натрий (Na)               🟡 Калий (K)
🔴 Фосфор (P)                🟡 Магний (Mg)
(из переработанной пищи)     (из свежей пищи)

РЕШЕНИЕ:
Больше овощей, бобовых, орехов, цельных зёрен
+ Читать этикетки на содержание Na и фосфатов
```
