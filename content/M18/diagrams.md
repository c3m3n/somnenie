# M18 — Схемы

## Дефицит vs профицит: состав изменения массы тела

| | Дефицит (−500 ккал/сут) | Профицит (+300 ккал/сут) |
|---|---|---|
| Белок ~1,6–2,2 г/кг | −Жир ↑↑, −Мышцы ↓ | +Мышцы ↑↑, +Жир ↓ |
| Белок ~0,8 г/кг | −Жир ↑, −Мышцы ↑ | +Мышцы ↓, +Жир ↑↑ |
| + Силовые тренировки | Сохраняет мышцы | Максимизирует мышцы |

> Состав тела = не только весы. −5 кг при низком белке ≠ −5 кг при высоком белке.

## Доза–ответ для белка (мышечный рост)

```
г белка за 1 приём (синтез мышечного белка):
0–20 г  [░░░░░░] Субоптимально
20–40 г [████████████] Оптимальная зона
40+ г   [████████████░] Дополнительная польза минимальна
         (избыток окисляется / идёт на энергию)
```

Суточная потребность:
- Поддержание: 1,2–1,6 г/кг
- Рост мышц: 1,6–2,2 г/кг
- Снижение веса + сохранение мышц: 2,0–3,0 г/кг (гипокалорийный фон)

## Углеводы и спортивное питание

| Ситуация | Рекомендация |
|---|---|
| Тренировка < 1 ч, умеренная | Не нужна специальная загрузка |
| Тренировка 1–3 ч | 30–60 г углеводов/ч во время |
| Тренировка > 3 ч | 60–90 г/ч (смесь глюкоза+фруктоза) |
| Восстановление (после) | 1–1,2 г/кг углеводов в первые 4 ч |
| Углеводная загрузка | За 1–3 дня до соревнований: 10–12 г/кг/сут |

## Добавки с доказательной базой (класс A)

| Добавка | Эффект | Доза |
|---|---|---|
| Креатин моногидрат | ↑ Мощность, ↑ мышечная масса | 3–5 г/сут |
| Кофеин | ↑ Выносливость, ↑ мощность | 3–6 мг/кг за 1 ч до |
| Бета-аланин | ↓ Усталость при высокой интенсивности | 3,2–6,4 г/сут |
| Нитраты (свёкла) | ↑ Эффективность O₂ | 500 мл сока свёклы за 2–3 ч |
| Протеин (сывороточный) | Удобный источник белка | По потребности |

> Всё остальное (BCAA при достаточном белке, жиросжигатели, «тестобустеры») — нет убедительных RCT.
