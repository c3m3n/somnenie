# M11 — Практическое задание: «Мои группы риска и умные пары»

## Цель задания

Определить свои личные риски по железу, цинку, йоду и селену, составить «умные пары» продуктов для биодоступности и решить, нужны ли вам анализы.

---

## Оборудование

- Свой типичный рацион за неделю
- Соль с кухни (проверить упаковку!)
- Заметки

---

## Задание 1: Чек-лист групп риска (10 минут)

### Инструкция:
Пройдите по списку и отметьте своё:

| Фактор | Риск по | У меня? |
|---|---|---|
| Женщина 19–50, обильные менструации | Железо | |
| Веган/вегетарианец | Железо, цинк, (B12) | |
| Соль дома не йодированная | Йод | |
| Мало молочного, яиц, морепродуктов | Йод | |
| Частое донорство крови | Железо | |
| Болезни ЖКТ / бариатрия | Всё | |
| Беременность (планы) | Железо, йод | |
| Рацион в основном из злаков и бобовых без обработки | Цинк, железо | |

### Самопроверка:
- Сколько отметок набралось и по каким элементам?
- Проверили ли вы прямо сейчас упаковку своей соли на слово «йодированная»?

---

## Задание 2: Умные пары (10 минут)

### Инструкция:
Составьте 3 «пары биодоступности» из своих продуктов:
1. Негемовое железо + витамин C (пример: чечевица + болгарский перец / гречка + квашеная капуста).
2. Разнесите по времени железосодержащий приём и чай/кофе (≥1 час).
3. Для цинка: запланируйте замачивание бобовых/круп или ферментированный продукт.

### Самопроверка:
- Пары собраны из того, что вы реально едите?
- Чай/кофе у вас сейчас «заливает» железо в основном приёме?

---

## Задание 3: Нужен ли мне анализ? (5 минут)

### Инструкция:
По итогам Задания 1 решите по каждому элементу: «нет повода» / «есть повод — целевой анализ». Запишите для «есть повода» правильный тест: железо → ОАК + ферритин; B12 → сывороточный B12 (при пограничном — MMA); D → 25(OH)D.

### Самопроверка:
- Вы выбрали целевые тесты по симптомам/рискам, а не «панель на всё»?
- Что из найденного решается едой ещё до анализов?

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Чек-лист пройден честно, соль проверена | 3 балла |
| Три рабочие «умные пары» из своего рациона | 4 балла |
| Решение по анализам целевое и обоснованное | 3 балла |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Посчитайте примерное железо своего вчерашнего дня (этикетки + справочник) с поправкой на биодоступность: ×0,15 для смешанного рациона или ×0,08 для вегетарианского. Сравните «всосавшиеся миллиграммы» с потерями (~1 мг/сут у мужчин, ~1,5–2 мг у менструирующих женщин). Сходится ли баланс?
