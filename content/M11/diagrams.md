# M11 — Схемы

## Два пути всасывания железа

```
ГЕМОВОЕ (Fe²⁺)                    НЕ-ГЕМОВОЕ (Fe³⁺)
Мясо / птица / рыба               Растения / обогащённые продукты
        ↓                                   ↓
Прямое всасывание              Fe³⁺ → Fe²⁺ (витамин C, кислота)
Эффективность: 15–35%                       ↓
                                   Всасывание: 2–20%
                                   Ингибиторы: фитаты, полифенолы, Ca
```

> Витамин C × 3 при той же еде → всасывание не-гемового удваивается.
> Чай/кофе рядом с едой → снижение всасывания на 40–90%.

## Матрица риска дефицита железа

| Группа | Риск | Причина |
|---|---|---|
| Женщины 19–50 | 🔴 Высокий | Потери с менструацией |
| Беременные | 🔴 Высокий | Потребность ×2 |
| Вегетарианцы | 🟡 Средний | Только не-гемовое |
| Дети 0–5 лет | 🟡 Средний | Быстрый рост |
| Мужчины 19–50 | 🟢 Низкий | Нет физиологических потерь |
| Пожилые | 🟡 Средний | Сниженная кислотность желудка |

RDA: женщины 19–50 → 18 мг/сут; мужчины / постменопауза → 8 мг/сут.

## Быстрый справочник: ключевые микроэлементы

| Элемент | Роль | Дефицит | Источники |
|---|---|---|---|
| Цинк | Иммунитет, синтез белка, репродукция | Задержка роста, иммунодефицит | Мясо, устрицы, бобовые |
| Йод | Гормоны щитовидной железы | Гипотиреоз, кретинизм | Морепродукты, йодированная соль |
| Селен | Антиоксидант, Т4→Т3 | Кардиомиопатия (болезнь Кешана) | Бразильский орех (1–2 шт/сут) |
| Медь | Метаболизм железа, нейромедиаторы | Анемия, нейропатия | Орехи, печень, бобовые |
| Марганец | Синтез кости, антиоксидант | Редко при норм. питании | Цельные зёрна, орехи |

> Бразильский орех: 1–2 шт. = ~100 мкг Se (RDA 55 мкг). Больше → риск токсичности.

## Железо: симптомы и анализы

```
Запасы снижаются → Ферритин ↓ (первый маркер)
       ↓
Транспорт нарушается → Сывороточное железо ↓, ОЖСС ↑
       ↓
Синтез Hb нарушается → Гемоглобин ↓, Ht ↓ (явная анемия)
```

Клинические симптомы анемии: усталость, бледность, тахикардия, одышка при нагрузке, pica (тяга к льду/мелу).
