# M19 — Шпаргалка

## Принцип
> Общие правила курса — для **здорового новичка**. Особые группы = персональная настройка, часть ситуаций = к врачу.

## Возраст
- Пожилые: белок **≥1,0–1,2 г/кг** (саркопения), но учитывать жевание/аппетит/почки
- Дети/подростки: семейно, под контролем врача; без «сушек»

## Беременность / лактация
| Период | +ккал |
|---|---|
| 1-й триместр | ≈0 |
| 2-й | +340 |
| 3-й | +450 |
| Лактация | +450–500 |

- Ключевые: фолиевая, железо, кальций, D, холин, омега-3; обычно пренатальные добавки
- Не дефицит и не детокс

## Веганство (адекватно при планировании)
- **B12** — обязательно добавка/обогащённое
- Йод, **железо ≈1,8×** (+ витамин C), холин, витамин D

## Диабет / ХБП
- ADA: **нет идеального % БЖУ**, индивидуализация
- Риск гипогликемии на препаратах; при ХБП — белок/Na/K/P с диетологом
- Не менять рацион резко самостоятельно

## Аллергия
- Диагностика, не элиминация вслепую
- **Анафилаксия** (отёк горла, удушье, обморок) → эпинефрин + неотложка

## Тревожные сигналы → к врачу
Потеря >5% массы за 6–12 мес · РПП · беременность/ГВ · дети · хрупкие пожилые · диабет на препаратах · ХБП · анафилаксия
