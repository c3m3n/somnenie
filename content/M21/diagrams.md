# M21 — Схемы

## Принцип тарелки (практическое планирование)

```
┌─────────────────────────────────────┐
│                                     │
│   ОВОЩИ / САЛАТ      │  КРУПЫ /     │
│   некрахмалистые     │  БОБОВЫЕ     │
│   (½ тарелки)        │  (¼ тарелки) │
│                      ├──────────────┤
│                      │  БЕЛОК       │
│                      │  (¼ тарелки) │
│                                     │
│      + стакан воды / молока         │
└─────────────────────────────────────┘
```

Метод тарелки работает без весов и подсчёта — снижает когнитивную нагрузку.
Ограничение: не учитывает индивидуальный TDEE и цели (спортсмен vs дефицит).

## Метод руки (портативные «весы»)

| Часть руки | Что мерит | Объём примерно |
|---|---|---|
| Кулак | Углеводы (крупы, фрукты) | 1 порция ≈ 150–200 г |
| Ладонь (толщина) | Белок (мясо, рыба, тофу) | 1 порция ≈ 85–110 г |
| Горсть | Орехи, сухофрукты | 1 порция ≈ 30 г |
| Большой палец | Жиры (масло, орехи кусочком) | 1 порция ≈ 10–15 г |

> Рука масштабируется под тело: у крупного человека рука больше → порция больше. Элегантно.

## Снижение трений: среда определяет выбор

| Цель | Высокое трение (затрудни) | Низкое трение (облегчи) |
|---|---|---|
| Больше овощей | Спрятать за другими продуктами | Нарезанные овощи на уровне глаз в холодильнике |
| Меньше сладкого | Убрать с видного места | Фрукты на столе вместо конфет |
| Пить воду | Не иметь бутылки рядом | Бутылка воды на рабочем столе всегда |
| Меньше перекусов | Нет удобной еды под рукой | Запланировать перекус заранее |

> Окружение формирует выбор сильнее, чем сила воли. Изменяй среду, не себя.

## Практические форматы планирования

| Формат | Уровень контроля | Для кого |
|---|---|---|
| Метод тарелки | Минимальный | Начинающие, повседневная жизнь |
| Метод руки | Средний | Без весов, на ходу |
| Шаблон недели | Средний | Планирование закупок |
| Трекинг (MyFitnessPal и др.) | Высокий | Спортсмены, точная цель |
| Взвешивание всей еды | Максимальный | Соревновательные атлеты |

> Лучший метод = тот, который ты выполняешь. Начни с простого.
