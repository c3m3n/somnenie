# M15 — Практическое задание: «Накорми экосистему и разоблачи этикетку»

## Цель задания

Оценить «рацион своей микробиоты», добавить разнообразие растительных субстратов и применить словарь ISAPP к реальным продуктам с «про-/пребиотическими» обещаниями.

---

## Оборудование

- Список своей еды за 3 дня
- 2–3 продукта с заявлениями «пробиотик / пребиотик / для здоровья кишечника» (из магазина или интернета)
- Заметки

---

## Задание 1: Счётчик растительного разнообразия (10 минут)

### Инструкция:
1. Выпишите ВСЕ разные растения, съеденные за 3 дня: овощи, фрукты, бобовые, злаки, орехи, семена, зелень, специи (каждый вид — один балл).
2. Цель-ориентир: ~30 разных растений в неделю (≈13–15 за 3 дня).
3. Отметьте отдельно источники ферментируемых волокон: бобовые, овёс, лук/чеснок, бананы.

### Самопроверка:
- Сколько баллов набралось? Какие категории пустуют (семена? бобовые?)
- Что проще всего добавить на следующей неделе ради +5 видов?

---

## Задание 2: Словарь ISAPP против этикетки (15 минут)

### Инструкция:
Для каждого «кишечного» продукта определите по строгим определениям:

| Продукт | Заявление | Это пробиотик? (живые штаммы + доза + доказанная польза) | Это пребиотик? (селективный субстрат) | Или просто ферментированный? |
|---|---|---|---|---|
| | | | | |

### Самопроверка:
- Указаны ли на этикетке конкретные штаммы и КОЕ (CFU)?
- Заявлена ли польза, которую можно проверить, или «поддерживает баланс» (непроверяемо)?

---

## Задание 3: Фраза-детектор хайпа (5 минут)

### Инструкция:
Найдите в интернете/рекламе 2 фразы из набора: «восстанови микробиом за 30 дней», «убей плохие бактерии», «анализ микробиома подберёт диету», «дырявый кишечник — причина всего». Для каждой напишите по одному предложению: что наука говорит на самом деле.

### Самопроверка:
- Ваше опровержение опирается на модуль (AGA, ISAPP, ферментация), а не на «мне кажется»?

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Честный счётчик разнообразия с планом +5 видов | 4 балла |
| Продукты корректно классифицированы по ISAPP | 4 балла |
| Два хайп-заявления опровергнуты по существу | 2 балла |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Спроектируйте «неделю для микробиоты» без единой добавки: по дням распишите источники клетчатки (14 г/1000 ккал), 3+ ферментированных продукта и 25+ видов растений. Проверьте план на реалистичность: вы будете так есть, или это «героический» план из M07?
