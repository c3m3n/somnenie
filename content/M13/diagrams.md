# M13 — Диаграммы и схемы

## Диаграмма 1: Два состояния — один переключатель

**Тип:** Двухпанельная схема с тумблером

**Элементы, которые должны быть на иллюстрации:**
- Тумблер в центре: «ИНСУЛИН ↑ / ГЛЮКАГОН ↑»
- Панель «Сытое состояние»: стрелки внутрь складов — глюкоза → гликоген (печень, мышцы); жир → триглицериды жировой ткани; аминокислоты → синтез белка
- Панель «Голодное состояние»: стрелки из складов — гликогенолиз → глюкоза крови; липолиз → жирные кислоты; печень → кетоны (при длительном голоде)
- Подпись: «Переключает гормон, а не сила воли»

## Диаграмма 2: Три склада

**Тип:** Схема-кладовая

**Элементы, которые должны быть на иллюстрации:**
- Склад 1 «Гликоген» — небольшой шкаф с биркой «буфер на часы–сутки; печень и мышцы»
- Склад 2 «Жировая ткань» — большой ангар с бирками «стратегический запас» и «эндокринный орган: выделяет лептин → M14»
- Склад 3 «Белок» — перечёркнутый контур склада: «ДЕПО НЕТ; избыток аминокислот → окисление / другие пути»
- Сравнительный масштаб складов (гликоген ~2000 ккал vs жир — десятки тысяч)

## Диаграмма 3: Хронология голодания

**Тип:** Временная шкала с эстафетой топлива

**Элементы, которые должны быть на иллюстрации:**
- Ось времени: часы → сутки → дни
- Полоса 1 «Гликогенолиз» — высокая в начале, тает к 24–48 ч
- Полоса 2 «Глюконеогенез» — нарастает по мере таяния гликогена (субстраты: лактат, глицерин, аминокислоты)
- Полоса 3 «Липолиз/жирные кислоты» — растёт со временем
- Полоса 4 «Кетоновые тела» — появляется при длительной нехватке углеводов, пометка «топливо для мозга»

## Диаграмма 4: Метаболическая гибкость

**Тип:** Маятник топлива

**Элементы, которые должны быть на иллюстрации:**
- Маятник между «Глюкоза (после еды)» и «Жир (между приёмами, нагрузка, сон)»
- Зелёная подпись «гибкий метаболизм: маятник качается свободно»
- Красная подпись «инсулинорезистентность/ожирение: маятник вязнет»
- Стрелка-улучшение: «физическая активность смазывает механизм»
- Плашка-антимиф: «"Метаболизм сломался" — нет; он может медленнее переводить стрелки»
