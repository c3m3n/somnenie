# M13 — Схемы

## Два метаболических состояния

| | Сытое (Fed) | Голодное (Fasted) |
|---|---|---|
| Инсулин | ↑ Высокий | ↓ Низкий |
| Глюкагон | ↓ Низкий | ↑ Высокий |
| Основной источник энергии | Глюкоза из пищи | Гликоген → жирные кислоты → кетоны |
| Глюкоза | Хранится (гликоген, жир) | Производится (гликогенолиз, глюконеогенез) |
| Анаболизм/катаболизм | Анаболизм | Катаболизм |

> Переключение Fed → Fasted занимает 4–8 ч после еды (не мгновенно).

## Три топливных хранилища

| Хранилище | Ёмкость | Быстрый доступ | Длительность |
|---|---|---|---|
| Гликоген (печень) | ~100 г | ✓ Да | ~4–6 ч покоя |
| Гликоген (мышцы) | ~300–500 г | Только локально | Для той же мышцы |
| Жировая ткань | 100 000+ ккал | ✗ Медленно | Недели–месяцы |
| Белок (мышцы) | ~25 000 ккал | ✗ Нежелательно | Крайний резерв |

> При голодании мозг → сначала глюкоза → потом кетоны (после 2–3 сут).

## Временная шкала голодания

```
0–4 ч    Постпрандиальная фаза: глюкоза из пищи
4–16 ч   Гликоген печени → поддержание гликемии
16–24 ч  Гликоген исчерпан → глюконеогенез (лактат, глицерол, АК)
24–48 ч  Кетогенез нарастает → мозг переходит на кетоны
> 48 ч   Кетоны = основное топливо мозга; мышечный белок расходуется медленнее
```

> ИГ 16:8 → человек практически не выходит за рамки 16 ч → до кетоза не доходит.

## Глюконеогенез: из чего делается глюкоза

```
Лактат (из мышц) ──┐
Глицерол (из жира) ─┤──→ Глюкоза (в печени и почках)
Аминокислоты ───────┘
(особенно аланин, глутамин)
```

Запускается при: голодании, низкоуглеводной диете, интенсивных тренировках.
