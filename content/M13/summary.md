# M13 — Шпаргалка

## Модель модуля
> **Используй сейчас → запаси на потом → достань, когда нужно.**
> Переключатель — гормоны (инсулин ↔ глюкагон+контргормоны), не сила воли.

## Сытое состояние (инсулин ↑)
- Глюкоза → ткани + **гликоген** (печень = буфер глюкозы крови)
- Жир → **триглицериды жировой ткани**
- Аминокислоты → **синтез белка** (депо белка НЕТ)

## Голодное состояние (инсулин ↓)
1. **Гликогенолиз** — печень тратит гликоген (часы)
2. **Глюконеогенез** — глюкоза из лактата, глицерина, аминокислот (когда гликоген тает)
3. **Липолиз** — жировая ткань отдаёт жирные кислоты
4. **Кетоны** — при длительной нехватке углеводов; топливо и для мозга

## Анаболизм / катаболизм
- Строить-запасать / разбирать-мобилизовать
- Не «хорошо/плохо» — два такта, которые тело чередует ежесуточно

## Жировая ткань
- Главный долгосрочный резервуар + **эндокринный орган** (лептин → M14)

## Метаболическая гибкость
- Умение переключать топливо: глюкоза после еды ↔ жир между приёмами/при нагрузке
- Страдает при ожирении/инсулинорезистентности, улучшается активностью

## Антимифы
- «Углеводы сразу в жир» — нет: сначала использование и гликоген-буфер; жир — при **устойчивом избытке энергии**
- «Метаболизм сломался» — нет: переключения работают у всех, разница в эффективности
