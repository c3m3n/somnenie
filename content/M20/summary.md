# M20 — Шпаргалка

## Порядок чтения (оборот > фронт)
1. **Размер порции** + число порций → пересчёт на реально съеденное
2. **Состав** — порядок по массе; имена сахара
3. **Скепсис** к фронтовым claim'ам
4. **Сравнение по %DV**

## Размер порции
- Сколько обычно едят, **не** рекомендация
- Пачка с 3 порциями + съел всё = всё ×3
- Бывает «двойная колонка» (порция / упаковка)

## Состав
- Порядок **убывания массы**: первый ингредиент — самый весомый
- Сахар прячется: sucrose, dextrose, сиропы, мёд, концентрат сока, всё на **-ose**
- «Нет слова сахар» ≠ «нет сахара»

## Claim'ы
- «No added sugar» ≠ «sugar-free» ≠ «calorie-free»
- «Fat-free» ≠ «без калорий» (часто жир заменён сахаром)
- «Natural/fitness/protein» — подсказка, не гарантия

## %DV
| %DV | Значение |
|---|---|
| ≤5% | низко (хорошо для Na, насыщенных жиров, сахара) |
| ≥20% | высоко (хорошо для клетчатки) |

> Контрольный вопрос: убрать лицевую сторону — продукт всё ещё силён по обороту?
