# M02 — Схемы

## Энергетический баланс

```
ПРИХОД > РАСХОД  →  набор массы  ↑
ПРИХОД = РАСХОД  →  стабильный вес  ↔
ПРИХОД < РАСХОД  →  снижение массы  ↓
```

> ⚠️ Тело — адаптивная система: при длительном дефиците расход тоже снижается.
> Для энергии нет RDA и нет UL → используется **EER** (расчётная потребность).

---

## Состав суточного расхода (TDEE)

```
BMR / RMR   [████████████████████████████] 60–70%  (основной обмен покоя)
Активность  [████████████]                20–30%  (тренировки + NEAT)
TEF         [████]                        ~10%    (переваривание пищи)
```

**NEAT** = бытовая активность: ходьба, стояние, ёрзанье, жесты — **не** спорт, **не** сон.

> BMR — самый крупный компонент, но **наименее управляемый**.
> Рычаг, который у нас реально есть: тренировки + NEAT (шаги, стояние).

---

## Формула Mifflin–St Jeor (RMR)

```
Мужчины:  9,99 × вес(кг) + 6,25 × рост(см) − 4,92 × возраст + 5
Женщины:  9,99 × вес(кг) + 6,25 × рост(см) − 4,92 × возраст − 161
```

TDEE = RMR × коэффициент активности:

| Уровень | Муж | Жен |
|---|---|---|
| Низкая активность | 1,11 | 1,12 |
| Активный | 1,25 | 1,27 |
| Очень активный | 1,48 | 1,45 |

> ⚠️ Расчёт — только **стартовая оценка**. Проверяй по динамике веса и корректируй.

## Термический эффект пищи (TEF) по нутриентам

| Нутриент | TEF |
|---|---|
| Жиры | 0–3% |
| Углеводы | 5–10% |
| Белки | 20–30% |
| Алкоголь | 10–30% |

> Клетчатка ≈ 2 ккал/г (меньше Atwater). Все калории — приблизительная оценка, не точное измерение.

> Миф «3500 ккал = всегда −1 фунт» — **неверно**: вес меняется нелинейно, расход адаптируется.
