# M22 — Схемы

## Воронка принятия решений о добавках

```
Есть подтверждённый дефицит (анализ)?
    Да → Добавка обоснована клинически
    Нет ↓

Есть риск-группа (беременность, веганство, пожилые)?
    Да → Профилактическая добавка обоснована
    Нет ↓

Есть убедительные RCT для здоровых с твоим профилем?
    Да → Возможно обоснована (оцени доза/риск)
    Нет ↓

        → Вероятно не нужна; приоритет — рацион
```

## Светофор доказательств для популярных добавок

| Добавка | Цвет | Комментарий |
|---|---|---|
| Витамин D (при дефиците) | 🟢 | Убедительные данные, широкий дефицит |
| Омега-3 (рыбий жир) | 🟢/🟡 | Польза для ССЗ — при высоком риске; у здоровых — спорно |
| Фолат (беременность) | 🟢 | Обязателен ДО зачатия |
| B12 (веганы) | 🟢 | Обязателен, нет растительных источников |
| Магний (при стрессе/сне) | 🟡 | Умеренные данные; часто есть дефицит |
| Цинк (иммунитет) | 🟡 | Снижает длительность ОРВИ при приёме в первые 24 ч |
| Коллаген | 🔴 | Расщепляется до АК; специфич. пептиды — слабые данные |
| Детокс-добавки | 🔴 | Нет механизма; нет RCT |
| «Жиросжигатели» | 🔴 | Нет убедительных данных; риск побочек |
| Пробиотики (здоровые) | 🔴 | Нет доказательств пользы для здоровых |

## Чеклист безопасности перед покупкой добавки

```
□ Есть ли RCT (рандомизированные контролируемые испытания)?
□ Штамм/форма/доза — те же, что в исследовании?
□ Сертификат качества: NSF, USP, Informed Sport?
□ Взаимодействие с лекарствами проверено?
□ UL (допустимый верхний уровень) — не превышен?
□ Консультация врача при хронических заболеваниях?
```
