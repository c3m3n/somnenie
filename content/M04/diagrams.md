# M04 — Схемы

## Роли белка в организме

| Роль | Что строит / делает | Пример |
|---|---|---|
| Структурная | Мышцы, соединительная ткань | Миозин, актин, коллаген |
| Ферментативная | Катализирует химические реакции | Амилаза, липаза, протеаза |
| Гормональная | Регулирует физиологию | Инсулин, глюкагон, ИФР-1 |
| Иммунная | Защита от патогенов | Иммуноглобулины (антитела) |
| Транспортная | Переносит молекулы в крови | Гемоглобин (O₂), альбумин (жиры) |
| Регуляторная (сигнальная) | Клеточная коммуникация | Рецепторные белки, цитокины |

> ⚠️ **Белкового депо нет.** В отличие от жиров и гликогена, белок не запасается «впрок». При дефиците организм разбирает собственные ткани — прежде всего мышечную массу.

## Комплементарность растительных белков

**Проблема:** большинство растительных источников — «неполные» (low score по одной или нескольким незаменимым аминокислотам).

| Источник | Лимитирующая АК | Как восполнить |
|---|---|---|
| Бобовые (чечевица, фасоль, нут) | Метионин ↓ | + Зерновые |
| Зерновые (рис, пшеница, овёс) | Лизин ↓ | + Бобовые |
| Кукуруза | Лизин ↓, триптофан ↓ | + Бобовые или молочные |

**Примеры комплементарных пар:**

```
Чечевица + рис          → полный аминокислотный профиль ✓
Хумус (нут) + лаваш     → полный аминокислотный профиль ✓
Фасоль + кукурузная тортилья → полный аминокислотный профиль ✓
```

**Исключение — соя:**

```
Соевый белок (тофу, темпе, эдамаме) → полный профиль без пары ✓
```

> ✓ Пары не обязательно есть в одном блюде — достаточно в течение дня. Разнообразие рациона решает задачу автоматически.

## Нормы потребления белка

| Группа | г / кг массы тела / день |
|---|---|
| Взрослый, малоподвижный | 0,8 |
| Регулярные тренировки (любительский уровень) | 1,2 – 1,6 |
| Силовые тренировки / наращивание массы | 1,6 – 2,2 |
| Плато роста мышц (опытные атлеты) | ~1,6 (выше — нет доп. эффекта) |
| Пожилые (65+) | 1,0 – 1,2 |
| Снижение массы тела при сохранении мышц | 1,6 – 2,4 |

**Качество белка — как оценивают:**

```
PDCAAS (устар.)  →  скорректированный аминокислотный скор по усвояемости
DIAAS  (актуален) →  учитывает усвояемость каждой АК в подвздошной кишке; точнее

Животный белок обычно DIAAS > 1,0
Растительный — 0,5–0,9 (соя ~0,9–1,0)
```

> ⚡ Практически: если рацион разнообразен и калорий достаточно — норма белка при смешанном или растительном питании достижима без добавок.
