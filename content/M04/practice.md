# M04 — Практическое задание: «Мой белковый день»

## Цель задания

Посчитать свою личную норму белка под цель, проверить фактический рацион на её соответствие и потренироваться в комплементарности растительных источников.

---

## Оборудование

- Весы (знать свой вес) и калькулятор
- Вчерашний день питания (по памяти или фото еды)
- Этикетки/таблицы калорийности для оценки белка в продуктах

---

## Задание 1: Моя норма (5 минут)

### Инструкция:
1. Определите свою категорию: без спорта / тренируюсь регулярно / возраст 65+.
2. Посчитайте диапазон: вес (кг) × норму (0,8 / 1,2–2,0 / 1,0–1,2 г/кг).
3. Запишите цель в граммах на день.

### Самопроверка:
- Ваша цифра — это минимум против дефицита или рабочий диапазон под цель?
- Если тренируетесь: ближе к 1,2 или к 2,0 — и почему?

---

## Задание 2: Аудит вчерашнего дня (15 минут)

### Инструкция:
Выпишите всё, что ели вчера, и оцените белок в граммах по каждому приёму:

| Приём | Еда | Белок (г) |
|---|---|---|
| Завтрак | | |
| Обед | | |
| Ужин | | |
| Перекусы | | |
| **Итого** | | |

### Самопроверка:
- Добрали ли вы свою норму из Задания 1?
- Как белок распределён по приёмам: равномерно или «всё вечером»?

---

## Задание 3: Растительная замена (10 минут)

### Инструкция:
Возьмите один свой приём пищи с животным белком и составьте растительную версию с тем же количеством белка, используя комплементарность (бобовые + зерновые, соя). Пример: курица с рисом → чечевица с рисом + йогурт.

### Самопроверка:
- Закрыты ли лимитирующие аминокислоты сочетанием источников?
- Что ещё «приехало» с растительной версией (клетчатка) и что ушло (насыщенные жиры)?

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Норма посчитана верно под свою категорию | 2 балла |
| Аудит дня с оценкой белка по приёмам | 4 балла |
| Корректная комплементарная замена | 3 балла |
| Сделан вывод о распределении по приёмам | 1 балл |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Сравните два белковых продукта (например, сывороточный протеин и гороховый) по этикеткам: белок на порцию, аминокислотный профиль (если указан), цена за 20 г белка. Сформулируйте вывод на уровне *рациона*: в каком случае разница реально имеет значение, а в каком — нет?
