# M09 — Практическое задание: «B-аудит и проверка мегадоз»

## Цель задания

Проверить свой рацион на источники витаминов группы B и C, оценить личные группы риска и разобрать одну «энергетическую» добавку критически.

---

## Оборудование

- Типичный недельный рацион
- Этикетка любого «витамина для энергии/иммунитета» (своего или из интернет-аптеки)
- Таблицы норм из теории

---

## Задание 1: Карта B и C (10 минут)

### Инструкция:
Отметьте, какие из источников есть в вашей неделе:

| Витамин | Ключевые источники | Есть у меня? |
|---|---|---|
| C | цитрусы, перец, киви, брокколи, ягоды | |
| B1 | цельные злаки, свинина, обогащённые крупы | |
| B2 | молоко, яйца, крупы | |
| B3 | мясо, птица, рыба | |
| B6 | нут, рыба, картофель, бананы | |
| B9 (фолат) | листовая зелень, бобовые | |
| B12 | мясо, рыба, яйца, молочное / обогащённое | |

### Самопроверка:
- Какие клетки пустые? Это и есть кандидаты на внимание.
- Если вы сильно ограничиваете животные продукты — чем закрыт B12?

---

## Задание 2: Мои группы риска (5 минут)

### Инструкция:
Отметьте применимое: веганство/строгое вегетарианство (B12); планирование беременности (фолат); регулярный алкоголь (B1); возраст 50+ (B12 — хуже всасывание); приём метформина или ингибиторов протонной помпы (B12); курение (+35 мг C).

### Самопроверка:
- Для отмеченных пунктов: что конкретно стоит изменить — еда, обогащённые продукты, разговор с врачом об анализе?

---

## Задание 3: Разбор «энергетической» добавки (10 минут)

### Инструкция:
Возьмите этикетку B-комплекса или «витаминов для энергии». Выпишите дозы и посчитайте, во сколько раз они превышают RDA:

| Витамин | Доза | RDA | Превышение |
|---|---|---|---|
| B6 | | 1,3 мг | |
| B12 | | 2,4 мкг | |
| Ниацин | | 16/14 мг | |
| Фолиевая к-та | | 400 мкг | |

### Самопроверка:
- Есть ли B6 выше EFSA UL 12 мг/сут или близко к US FNB UL 100 мг/сут? Есть ли фолиевая больше 1000 мкг?
- B12 «в 1000× от нормы» при нормальном статусе даст энергию? (Подсказка из теории: нет.)
- Сформулируйте: эта добавка решает чей-то дефицит или продаёт «энергию»?

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Карта источников заполнена честно | 3 балла |
| Определены личные группы риска с конкретным действием | 3 балла |
| Дозы добавки сопоставлены с RDA и UL | 3 балла |
| Сформулирован вывод «дефицит vs маркетинг» | 1 балл |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Найдите состав любого энергетика (Red Bull, Monster и т.п.) и выпишите дозы B-витаминов. Объясните с позиции модуля: почему «заряд бодрости» в них даёт кофеин и сахар, а не B12, и зачем тогда производитель кладёт туда витамины.
