# M09 — Диаграммы и схемы

## Диаграмма 1: Водорастворимые — транзитный путь

**Тип:** Схема потока с одним исключением

**Элементы, которые должны быть на иллюстрации:**
- Поток: Еда → Всасывание → Работа в тканях → Излишек с мочой (иконка капли)
- Ответвление-исключение: «B12 → депо в печени на годы» (иконка сейфа)
- Плашка: «"Выводится с мочой" ≠ "мегадозы полезны"»
- Три красных значка токсичности: B6 (нейропатия), ниацин (печень, приливы), фолиевая к-та (маскирует B12)

## Диаграмма 2: Семейный портрет группы B

**Тип:** Таблица-инфографика 7 строк

**Элементы, которые должны быть на иллюстрации:**
- Строки: B1 → бери-бери / алкоголизм; B2 → стоматит, хейлоз; B3 → пеллагра «3Д»; B6 → >100 реакций, UL зависит от юрисдикции; B9 → ДНК, нервная трубка; B12 → нервы + кровь, только животное
- Колонки: функция · главные источники · дефицит · опасность избытка
- Цветовое выделение: B9 и B12 в общей рамке «переплетённая пара»

## Диаграмма 3: Ловушка фолат–B12

**Тип:** Схема-развилка

**Элементы, которые должны быть на иллюстрации:**
- Старт: «Дефицит B12» → две стрелки:
  - «Анемия» — её закрывает большая доза фолиевой кислоты (зелёная маска на красном фоне), подпись «анализ выглядит нормально»
  - «Повреждение нервов» — продолжается (красная стрелка вниз), подпись «онемение, покалывание — без анемии!»
- Вывод-плашка: «Фолиевая кислота >1000 мкг может спрятать проблему, не решив её»

## Диаграмма 4: Мегадозы — что говорят данные

**Тип:** Три карточки «ожидание vs реальность»

**Элементы, которые должны быть на иллюстрации:**
- «Витамин C от простуды»: ожидание — щит; реальность — «не предотвращает, чуть сокращает длительность»
- «Ниацин для сердца»: ожидание — красивая липидограмма; реальность — «событий не меньше, побочек больше»
- «B12 для энергии»: ожидание — молния; реальность — «без дефицита эффекта нет»
- Общий вывод внизу: «Дефицит есть → восполнение преображает. Дефицита нет → сверху не работает»
