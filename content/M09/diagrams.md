# M09 — Схемы

## Диаграмма 1. Путь водорастворимых витаминов в организме

```
Пища
  │
  ▼
Всасывание в тонком кишечнике
  │
  ├──► Функция в тканях (коферменты, антиоксиданты)
  │
  ├──► Избыток → выводится с мочой
  │         (почки — «таможня»)
  │
  └──► ИСКЛЮЧЕНИЕ: Витамин B12
            │
            ▼
         Депо в печени
         (запас на 3–5 лет)
         → дефицит развивается медленно,
           симптомы появляются поздно
```

> **Ключевой принцип:** водорастворимые витамины не накапливаются в жире → риск токсичности ниже, но регулярное поступление важнее, чем для жирорастворимых.

### 🔴 Три предупреждения о превышении доз

| Витамин | Риск при избытке | Верхний допустимый уровень (UL) |
|---------|-----------------|--------------------------------|
| **B6 (пиридоксин)** | Сенсорная нейропатия (онемение, нарушение координации) | США: 100 мг/день · EFSA: **12 мг/день** |
| **B3 (ниацин)** | Токсическое поражение печени; «ниациновый флаш» (покраснение кожи) | 35 мг/день (ниацинамид — ниже риск флаша) |
| **B9 (фолат)** | Маскирует дефицит B12 → нервные повреждения продолжаются | 1000 мкг/день синтетической фолиевой кислоты |

## Диаграмма 2. Семья витаминов группы B — сводная таблица

| Витамин | Болезнь дефицита | Ключевые источники | Группа риска | Опасность избытка |
|---------|-----------------|-------------------|-------------|-------------------|
| **B1 (тиамин)** | Бери-бери (повреждение сердца и нервов) | Цельные зёрна, бобовые, свинина | Алкоголизм | Нет данных о токсичности из пищи |
| **B2 (рибофлавин)** | Стоматит, хейлоз (трещины губ), дерматит | Молоко, яйца, мясо субпродукты | Веганы без планирования | Нет данных о токсичности |
| **B3 (ниацин)** | Пеллагра (дерматит + диарея + деменция) | Мясо, рыба, орехи, грибы | Редко в развитых странах | ⚠️ Флаш, гепатотоксичность в высоких дозах |
| **B6 (пиридоксин)** | Анемия, дерматит, иммунодефицит | Нут, рыба, птица, картофель | Пожилые, алкоголизм | ⚠️ Нейропатия, UL варьирует по странам |
| **B9 (фолат)** | Мегалобластная анемия; дефекты нервной трубки плода | Листовая зелень, бобовые, печень | Беременные, женщины детородного возраста | ⚠️ Маскирует дефицит B12 |
| **B12 (кобаламин)** | Анемия + необратимое повреждение нервов | **Только животные продукты** (мясо, рыба, яйца, молоко) | Веганы, пожилые (↓ кислотность желудка) | Не описана токсичность при физиологических дозах |

## Диаграмма 3. Ловушка фолат–B12 (критическое взаимодействие)

| Параметр | Сценарий: высокий фолат без B12 |
|----------|--------------------------------|
| **Что происходит с кровью** | Фолат «чинит» мегалобластную анемию → анализ крови выглядит нормально ✓ |
| **Что происходит с нервами** | B12-дефицит продолжает разрушать миелин → нейропатия прогрессирует ✗ |
| **Результат** | Необратимые неврологические повреждения при «нормальном» анализе |
| **Механизм** | Фолат и B12 — партнёры в синтезе ДНК; фолат обходит дефицит B12 в одном пути, но не в нервном |

### Правила для практики

```
ПЕРЕД назначением фолиевой кислоты в дозах >400 мкг
        │
        ▼
Проверить статус B12 (сывороточный B12 и/или MMA, гомоцистеин)
        │
        ├── B12 в норме → можно назначать фолат
        │
        └── B12 снижен → СНАЧАЛА восполнить B12, затем фолат
```

> ⚠️ **Группы риска:** веганы, пожилые (атрофический гастрит → ↓ внутренний фактор), принимающие метформин или ИПП.

> **Анти-миф:** инъекции/таблетки B12 «для энергии» без подтверждённого дефицита — плацебо. B12 повышает энергию только при устранении реального дефицита.
