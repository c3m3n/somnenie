# M12 — Шпаргалка

## Конвейер
| Станция | Роль |
|---|---|
| Рот | жевание + слюнная амилаза (крахмал) |
| Желудок | кислота, пепсин (белок), внутренний фактор, дозатор — **не главный переваривател** |
| Тонкая кишка | **главное переваривание и всасывание** |
| Толстая | вода, электролиты, ферментация микробиотой |

## Секреты
- **Амилазы** → крахмал; **протеазы** (пепсин, трипсин и др.) → белок; **липаза** → жир
- **Желчь — НЕ фермент**: эмульгатор (печень → желчный пузырь → 12-перстная), мицеллы для жира и витаминов A/D/E/K

## Маршруты всасывания
- Углеводы → моносахариды → кровь → печень
- Белки → аминокислоты/пептиды → кровь
- **Жир → мицеллы → хиломикроны → ЛИМФА**
- Фолат — 12-перстная/тощая; **B12 — терминальная подвздошная + внутренний фактор**; желчные соли — рециркуляция в подвздошной

## Усвояемость vs биодоступность
- Усвояемость = насколько расщепилось; биодоступность = сколько реально всосалось
- «Есть в составе» ≠ «получил организм»

## Две поломки — две логики
| | Лактозная непереносимость | Целиакия |
|---|---|---|
| Категория | ферментная (лактаза↓) | иммунная (глютен, DQ2/DQ8) |
| Механизм | ферментация в толстой кишке | повреждение тонкой кишки → мальабсорбция |
| Стратегия | дозировать; лактаза; сыр/йогурт ок | строго без глютена, пожизненно |

> Не путать с **аллергией** на молоко/пшеницу (иммунная реакция на белок) и «нечувствительностью к глютену без целиакии» (симптомы без повреждения).
> Целиакия может вторично дать лактозную непереносимость.
