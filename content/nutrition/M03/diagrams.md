# M03 — Схемы

## Пирамида доказательств

```
        ╔══════════════════════════════════╗
        ║  Систематические обзоры          ║  ← наивысший уровень
        ║  и мета-анализы                  ║
        ╚══════════════════════════════════╝
              ↑  объединяют много РКИ
      ╔════════════════════════════════════════╗
      ║  Рандомизированные                     ║
      ║  контролируемые испытания (РКИ)        ║
      ╚════════════════════════════════════════╝
              ↑  причинно-следственная связь
  ╔════════════════════════════════════════════════╗
  ║  Наблюдательные исследования                   ║
  ║  (когортные, «случай–контроль», поперечные)    ║
  ╚════════════════════════════════════════════════╝
              ↑  ассоциации, не причины
╔══════════════════════════════════════════════════════╗
║  Мнения экспертов, кейс-репорты, анекдоты           ║  ← наименее надёжно
╚══════════════════════════════════════════════════════╝
```

> ⚠️ **Предупреждение:** «Исследования показали…» — не указание уровня. Один РКИ с 30 людьми слабее мета-анализа 50 РКИ. Лейбл ≠ качество.

## GRADE: факторы снижения уверенности

| Фактор | Что происходит с уверенностью |
|---|---|
| Риск систематической ошибки (bias) | ↓ при плохой рандомизации, незаслеплении |
| Непоследовательность результатов | ↓ если разные исследования дают разный эффект |
| Косвенность доказательств | ↓ изучали крыс или другую популяцию |
| Неточность (широкие ДИ) | ↓ маленькая выборка, большой разброс |
| Публикационная предвзятость | ↓ публикуют только «положительные» данные |

**Стартовая позиция по GRADE:**

```
РКИ          → начинает на уровне «Высокий»  → может снизиться
Наблюдение   → начинает на уровне «Низкий»   → редко повышается
```

## Чеклист для чтения нутритивного заявления

```
1. КТО изучали?
   └─ Возраст, пол, исходное здоровье, страна → применимо ли к вам?

2. ДИЗАЙН исследования?
   └─ Опрос / когорта / РКИ / мета-анализ → уровень пирамиды выше

3. С ЧЕМ СРАВНИВАЛИ?
   └─ Плацебо? Ничего? Другой продукт? Без контроля → нет доказательства

4. КАКОЙ ИСХОД измеряли?
   └─ Суррогатный маркер (уровень холестерина) ≠ смертность / болезнь

5. КТО ФИНАНСИРОВАЛ?
   └─ Индустрия → конфликт интересов → читать выводы осторожнее

6. РАЗМЕР ЭФФЕКТА и ДИ?
   └─ p < 0.05 ≠ клинически значимо; смотри абсолютный, а не относительный риск
```

> ✓ Заявление с источником лучше заявления без него. Но источник — только начало чтения, не его замена.
