# M24 — Схемы

## Разрыв знание–действие

```
ЗНАНИЕ                    ДЕЙСТВИЕ
«Надо есть больше овощей»  →  Фактически ем больше овощей?
         ↑                              ↑
    Курс пройден            Среда + привычки + идентичность
```

Что заполняет разрыв:
1. **Конкретный план** (что, когда, где) — не «буду есть лучше»
2. **Реализационные намерения**: «Когда [ситуация X], я сделаю [действие Y]»
3. **Среда**: убрать барьеры для нужного, добавить барьеры для ненужного
4. **Идентичность**: «Я человек, который...» (а не «Я пытаюсь...»)

---

## Формирование пищевой привычки

| Этап | Описание | Пример |
|---|---|---|
| 1. Триггер (Cue) | Сигнал, запускающий поведение | Обед = 13:00, рабочий стол убран |
| 2. Рутина (Routine) | Само поведение | Достать контейнер с едой |
| 3. Награда (Reward) | Подкрепление | Сытость + перерыв от работы |
| Идентичность | Кто ты? | «Я тот, кто готовит еду заранее» |

Средний срок формирования привычки: **66 дней** (диапазон 18–254, Lally 2010).
«21 день» — популярный миф без научного основания.

## Матрица трений окружающей среды

| Нежелательное поведение | ↑ Трение (как затруднить) | Желаемое поведение | ↓ Трение (как облегчить) |
|---|---|---|---|
| Перекус чипсами | Не хранить дома | Перекус орехами | Готовая порция на рабочем столе |
| Пропуск завтрака | — | Завтрак | Ингредиенты готовы с вечера |
| Фастфуд в обед | Не брать карту без плана | Домашняя еда | Контейнер с едой в сумке |
| Поздний перекус | Не покупать | Ранний ужин | Запланировать время |

## Долгосрочная стратегия: что работает по данным науки

```
✓ Гибкость, не жёсткость: «80/20», а не «всё или ничего»
✓ Самомониторинг: отслеживание поддерживает осознанность
✓ Планирование: готовая еда снижает решения под давлением
✓ Социальная поддержка: партнёр / сообщество → выше соблюдение
✓ Прощение сбоев: один плохой день ≠ провал стратегии
✓ Принцип наименьшего вмешательства: минимум изменений с максимумом эффекта

✗ Перфекционизм → выгорание и отказ от системы
✗ Экстремальные ограничения → срывы и рикошет
✗ Опора только на силу воли → истощение ресурса
```
