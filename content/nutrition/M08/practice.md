# M08 — Практическое задание: «A, D, E, K в моей тарелке»

## Цель задания

Найти жирорастворимые витамины в своём реальном рационе, оценить личные факторы риска по витамину D и проверить свои добавки (если есть) на разумность доз.

---

## Оборудование

- Свой типичный недельный рацион (по памяти)
- Упаковки добавок/мультивитаминов, если принимаете
- Таблица норм из теории модуля

---

## Задание 1: Карта источников (10 минут)

### Инструкция:
Для каждого витамина выпишите из своего рациона 2–3 реальных источника:

| Витамин | Мои источники | Как часто ем |
|---|---|---|
| A (ретинол: печень, яйца, молочное) | | |
| A (каротиноиды: морковь, тыква, зелень) | | |
| D (жирная рыба, обогащённые продукты) | | |
| E (орехи, семена, масла) | | |
| K (листовая зелень, масла) | | |

### Самопроверка:
- По какому витамину источников меньше всего?
- Есть ли в приёмах с овощами немного жира (масло, орехи) для всасывания?

---

## Задание 2: Мой риск по витамину D (5 минут)

### Инструкция:
Отметьте свои факторы риска: мало солнца (офис/зима/северная широта); солнцезащитный крем постоянно; тёмная кожа; возраст 65+; ожирение; нарушения ЖКТ; не ем жирную рыбу и обогащённые продукты.

### Самопроверка:
- Сколько факторов набралось? При 2–3 и более — разумный кандидат на анализ 25(OH)D (не 1,25-формы!).
- Ваш ориентир достаточности: ≥ 50 нмоль/л (20 нг/мл).

---

## Задание 3: Аудит добавок (10 минут)

### Инструкция:
Если принимаете мультивитамины или отдельные добавки — выпишите дозы A, D, E, K с этикетки и сравните с RDA и UL:

| Витамин | Доза в добавке | RDA | UL |
|---|---|---|---|
| A | | 900/700 мкг RAE | 3000 мкг (преформ.) |
| D | | 15–20 мкг (600–800 МЕ) | 100 мкг (4000 МЕ) |
| E | | 15 мг | 1000 мг |
| K | | 120/90 мкг | нет |

Если добавок нет — проанализируйте состав любого аптечного мультивитамина по фото/сайту.

### Самопроверка:
- Есть ли позиции, где добавка даёт в разы больше RDA? Зачем?
- Витамин A в форме ретинола или β-каротина? (Для UL важна форма.)

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Карта источников заполнена по всем четырём витаминам | 3 балла |
| Учтён жир в приёмах для всасывания | 1 балл |
| Оценён личный риск по витамину D с выводом | 3 балла |
| Аудит добавок с сопоставлением RDA/UL | 3 балла |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Разберите упаковку печени трески (или говяжьей печени): посчитайте, сколько преформированного витамина A даёт реальная порция, и сопоставьте с UL 3000 мкг RAE. Сделайте вывод: как часто такой продукт разумно есть и почему «полезное» не значит «ежедневное».
