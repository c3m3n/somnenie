# M20 — Практическое задание: «Детектив на кухне»

## Цель задания

Отработать порядок чтения этикетки на реальных продуктах: пересчёт на порцию, разбор состава, разоблачение claim'ов и сравнение по %DV.

---

## Оборудование

- 3–4 упаковки с этикетками (батончик, хлопья, йогурт, соус)
- Калькулятор
- Теория модуля

---

## Задание 1: Пересчёт на реально съеденное (10 минут)

### Инструкция:
Для каждого продукта выпишите serving size и число порций, затем прикиньте, сколько вы реально съедаете, и пересчитайте калории/сахар/натрий.

| Продукт | Порция | Порций в упаковке | Реально съедаю | Ккал фактически |
|---|---|---|---|---|
| | | | | |

### Самопроверка:
- Где ваша реальная порция в 2–3 раза больше «официальной»?
- Изменилось ли впечатление о продукте после пересчёта?

---

## Задание 2: Первые три ингредиента (10 минут)

### Инструкция:
Для каждого продукта выпишите первые 3 ингредиента и найдите все «имена сахара» в составе (sucrose, сиропы, мёд, концентрат сока, -ose).

### Самопроверка:
- У какого продукта сахар (в любом имени) стоит в первых строках?
- Совпадает ли это с тем, что обещает лицевая сторона?

---

## Задание 3: Дуэль по %DV (10 минут)

### Инструкция:
Возьмите два похожих продукта и сравните при сопоставимых порциях по %DV: добавленные сахара, насыщенные жиры, натрий (хотим низкое, ≤5%), клетчатка (хотим высокое, ≥20%), белок.

### Самопроверка:
- Какой продукт выигрывает по комбинации признаков?
- Совпал ли «победитель по обороту» с «победителем по фронту»?

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Пересчёт на реальную порцию выполнен | 3 балла |
| Найдены имена сахара в составах | 3 балла |
| Сравнение по %DV при сопоставимых порциях | 3 балла |
| Сделан вывод «фронт vs оборот» | 1 балл |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Найдите продукт, где лицевая сторона и оборот максимально расходятся (громкий claim при слабом составе). Сфотографируйте/опишите обе стороны и сформулируйте, какой именно приём маркетинга использован и как оборот его опровергает.
