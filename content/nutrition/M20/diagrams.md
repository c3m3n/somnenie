# M20 — Схемы

## Порядок чтения этикетки

```
1. РАЗМЕР ПОРЦИИ (serving size)
   └─ Все данные ниже — на эту порцию, не на упаковку!

2. КАЛОРИИ (ккал на порцию)
   └─ Умножь на кол-во порций, которые ты реально съешь

3. НУТРИЕНТЫ ОГРАНИЧЕНИЯ (% от суточной нормы)
   └─ Насыщ. жиры, транс-жиры, натрий, добавл. сахар → меньше = лучше

4. НУТРИЕНТЫ ДОСТАТОЧНОСТИ
   └─ Клетчатка, витамины, минералы → больше = лучше

5. СПИСОК ИНГРЕДИЕНТОВ
   └─ По убыванию массы; первые 3 = основа продукта
```

## Ловушка размера порции

| Продукт | Размер порции (этикетка) | Реальное потребление | Разница |
|---|---|---|---|
| Чипсы | 30 г (≈10 чипсов) | 90–100 г (полпачки) | ×3 калории |
| Кукурузные хлопья | 30 г | 60–80 г | ×2–2,5 |
| Газировка | 240 мл (1 стакан) | 500–600 мл (бутылка) | ×2 |
| Орехи | 28 г (≈23 миндалины) | 50–70 г | ×2–2,5 |

> «Размер порции» = типичное потребление для маркировки, не рекомендация к употреблению.

## Декодер маркетинговых заявлений

| Заявление | Что это значит реально |
|---|---|
| «Без сахара» | Нет добавленного сахара; могут быть сахарные спирты |
| «Обезжиренный» | ≤0,5 г жира на порцию; часто ↑ сахар/крахмал для вкуса |
| «Натуральный» / «Natural» | Юридически не регулируется в РФ и в большинстве стран |
| «Фитнес» / «Лёгкий» | Нет стандарта; маркетинговое слово |
| «Без ГМО» | ГМО-статус не связан с безопасностью или питательностью |
| «Богат клетчаткой» | В EU: ≥6 г/100 г; в РФ: нет стандарта |
| «Источник белка» | В EU: ≥12% ккал из белка |

## % суточной нормы: шкала быстрой оценки

```
≤ 5% ДН   → МАЛО   (этот нутриент почти не вносит вклад)
5–19% ДН  → УМЕРЕННО
≥ 20% ДН  → МНОГО  (хорошо для клетчатки; плохо для натрия/сахара)
```

Пример: натрий 920 мг = 40% ДН → один продукт = почти половина дневного лимита.
