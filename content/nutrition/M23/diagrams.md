# M23 — Схемы

## Универсальный фильтр оценки диеты

```
1. Создаёт ли устойчивый дефицит/профицит энергии? (без этого — нет эффекта)
        ↓ Да
2. Обеспечивает ли достаточно белка (≥1,2 г/кг)?
        ↓ Да
3. Покрывает ли микронутриенты (или есть план добавок)?
        ↓ Да
4. Подходит ли твоему образу жизни на срок > 6 мес?
        ↓ Да
→ ДИЕТА РАБОТАЕТ (механизм — через п.1, остальное — инструменты)
        ↓ Нет на любом пункте
→ РИСК ПРОВАЛА / ВРЕДА
```

## Популярные диеты: что за занавесом

| Диета | Механизм похудения (реальный) | Риски |
|---|---|---|
| Кето | Дефицит калорий + ↓ аппетит (кетоны, ↑ белок) | Дефицит клетчатки, кальция; кето-грипп |
| Интервальное голодание | Дефицит за счёт уменьшения окна питания | Не лучше равного дефицита по данным RCT |
| Палео | Исключение ультрапереработки → дефицит | Нет доказательств «эволюционной» пользы |
| Средиземноморская | Высокое качество продуктов, клетчатка, ненасыщ. жиры | Нет строгих ограничений = сложнее создать дефицит |
| Детокс-диеты | Временное снижение ккал → потеря воды/гликогена | Нет детоксикации; рикошет |
| Низкожировая (до 90-х) | Дефицит через ↓ плотную по ккал пищу | Без ограничения общих ккал — не работает |

## Таблица мифов о диетах

| Миф | Реальность |
|---|---|
| «Кето = лучшее жиросжигание» | При одинаковом дефиците потеря жира одинакова |
| «Нельзя есть углеводы после 18:00» | Время не влияет; важен суточный баланс |
| «Молочное → слизь» | Нет механизма; опровергнуто в RCT |
| «Дробное питание ускоряет метаболизм» | Частота приёмов не влияет на TDEE |
| «Веганство всегда полезнее» | Зависит от качества рациона, а не статуса |
| «Сахар = яд (токсичен в любой дозе)» | Вред — от избытка калорий и замены нутриентов |

## Признаки псевдонаучной диеты

```
🚩 Обещает быстрый результат (> 1 кг/нед жира)
🚩 Исключает целую группу продуктов без медицинских показаний
🚩 Требует покупки специальных продуктов / добавок автора
🚩 Апеллирует к «детоксу», «ощелачиванию», «воспалению» без анализов
🚩 Ссылается на «древних предков» или «скрытые знания»
🚩 Нет ни одного RCT в поддержку
```
