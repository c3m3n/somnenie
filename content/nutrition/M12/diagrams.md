# M12 — Схемы

## Конвейер пищеварения

| Орган | Что происходит | Ключевые агенты |
|---|---|---|
| Рот | Механическое измельчение, амилаза | Слюна, жевание |
| Желудок | Денатурация белков, кислая среда | HCl (pH 1,5–3,5), пепсин |
| Тонкий кишечник | Основное всасывание (85–90%) | Панкреатические ферменты, желчь |
| Толстый кишечник | Вода, электролиты, ферментация клетчатки | Микробиота |
| Почки / Печень | Метаболизм и выведение | Фильтрация, детоксикация |

> Желудок — не главное место всасывания (только алкоголь и некоторые лекарства).

## Три субстратных пути

```
УГЛЕВОДЫ → Глюкоза → Гликолиз → Пируват → АцКоА → Цикл Кребса → АТФ
ЖИРЫ → Жирные кислоты → β-окисление ────────────────→ АцКоА → Цикл Кребса → АТФ
БЕЛКИ → Аминокислоты → Дезаминирование → Пируват / АцКоА / промежуточные ЦК → АТФ
                                                              ↓
                                                    Мочевина (выведение N)
```

> Все три сходятся в ацетил-КоА → общий финальный путь к ATP и теплу.

| | Углеводы | Жиры | Белки |
|---|---|---|---|

## Биодоступность: почему «сколько съел ≠ сколько усвоил»

```
Съедено 100%
    ↓
Переварено (химически расщеплено)   → −10–30%  (клетчатка, сырые крахмалы)
    ↓
Всосано (поступило в кровь)          → −5–20%   (антипитательные вещества)
    ↓
Использовано клетками                → = реальная биодоступность
```

Приготовление пищи (тепловая обработка) → ↑ биодоступность белков и крахмалов.
Замачивание бобовых → ↓ фитаты → ↑ всасывание Zn, Fe.
