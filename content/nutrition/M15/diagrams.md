# M15 — Схемы

## Экосистема кишечника

```
Пища (клетчатка, пребиотики)
        ↓
Толстый кишечник → Ферментация микробиотой
        ↓
Короткоцепочечные жирные кислоты (КЖК): бутират, пропионат, ацетат
        ↓
Питание колоноцитов + Регуляция иммунитета + Снижение воспаления
```

> Бутират = основное топливо клеток кишечника. Дефицит клетчатки → дефицит КЖК.
> ~100 трлн микробных клеток, >1000 видов, ~1,5 кг — индивидуальный «отпечаток».

## Словарь ISAPP (официальные определения)

| Термин | Определение | Пример |
|---|---|---|
| Пробиотик | Живые микроорганизмы, при достаточном количестве дающие пользу здоровью | Lactobacillus, Bifidobacterium |
| Пребиотик | Субстрат, избирательно используемый микроорганизмами с пользой для хозяина | Инулин, ФОС, ГОС |
| Синбиотик | Сочетание пробиотика + пребиотика | Йогурт с инулином |
| Постбиотик | Неживые микроорганизмы / их компоненты с пользой для здоровья | Убитые нагревом бактерии, КЖК |

> «Полезные бактерии» ≠ всегда пробиотик по ISAPP. Нужен конкретный штамм + доза + RCT.

## Уровни доказательности для микробиоты

| Состояние | Уровень доказательств |
|---|---|
| Некротический энтероколит (недоношенные) | ✅ Убедительный |
| C. difficile (профилактика рецидивов) | ✅ Убедительный |
| ВЗК (индукция ремиссии) | 🟡 Умеренный |
| СРК (симптомы) | 🟡 Умеренный |
| Диарея путешественников | 🟡 Умеренный |
| Иммунитет у здоровых | 🔴 Слабый/неубедительный |
| Потеря веса | 🔴 Слабый/неубедительный |

> Разные штаммы = разные эффекты. Acidophilus от диареи ≠ Rhamnosus от аллергии.

## Факторы, формирующие микробиоту

```
ПОЗИТИВНЫЕ                    НЕГАТИВНЫЕ
─────────────────             ─────────────────
Клетчатка ≥25–38 г/сут  ↑   Антибиотики       ↓
Ферментир. продукты     ↑   Ультрапереработка  ↓
Разнообразие рациона    ↑   Стресс хронич.     ↓
Физическая активность   ↑   Дефицит сна        ↓
Грудное вскармливание   ↑   Чрезмерный сахар   ↓
```
