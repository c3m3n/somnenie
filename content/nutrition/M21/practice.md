# M21 — Практическое задание: «Мой повторяемый шаблон»

## Цель задания

Собрать рабочий шаблон питания без весов: тарелки на день, список «база дома» и продуманные перекусы — так, чтобы полезный выбор стал самым лёгким.

---

## Оборудование

- Свой обычный день/неделя
- Холодильник и шкаф (аудит запасов)
- Принцип тарелки и порции «на глаз» из теории

---

## Задание 1: Три тарелки (10 минут)

### Инструкция:
Соберите завтрак, обед и ужин по принципу тарелки (½ овощи, ¼ белок, ¼ гарнир), используя продукты, которые реально едите. Белок прикиньте «ладонью».

| Приём | Овощи (½) | Белок (¼) | Гарнир (¼) |
|---|---|---|---|
| Завтрак | | | |
| Обед | | | |
| Ужин | | | |

### Самопроверка:
- Где проседают овощи или белок?
- Баланс складывается за день, даже если один приём неидеален?

---

## Задание 2: База дома (10 минут)

### Инструкция:
Составьте свой список «всегда в наличии»: 2–3 быстрых белка, 2–3 гарнира, овощи (можно замороженные/нарезанные), фрукты, 2 «безопасных» быстрых блюда на усталость.

### Самопроверка:
- Из этой базы можно собрать ужин за 10–15 минут?
- Что из списка сейчас отсутствует и попадёт в ближайшую покупку?

---

## Задание 3: Два перекуса-конструктора (5 минут)

### Инструкция:
Придумайте 2 перекуса по формуле «белок или клетчатка + удобство» из доступных продуктов и решите, где их держать наготове (работа, дом).

### Самопроверка:
- Перекусы реально под рукой в нужный момент?
- Они помогают не приходить домой на грани переедания?

---

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Три тарелки собраны по принципу с белком «на глаз» | 4 балла |
| Список «база дома» составлен и проверен на быстрый ужин | 3 балла |
| Два перекуса-конструктора с местом хранения | 3 балла |
| **Максимум** | **10 баллов** |

---

## Дополнительное задание (повышенная сложность)

Возьмите своё любимое «вредное» блюдо и встройте его в неделю намеренно (по логике 80/20), а не запрещайте. Опишите, как при этом сохранить структуру остальных дней, чтобы один любимый приём не превращался в «всё пропало».
