# M01 — Шпаргалка

## Три уровня разговора о питании
| Уровень | Что это | Пример |
|---|---|---|
| Нутриент | Химическое вещество | «сахар», «белок» |
| Продукт | Конкретная еда, матрица | сок ↔ цельный фрукт |
| Рацион | Привычный паттерн | как ем в целом |

> **Главное правило M01:** большинство мифов = путаница уровней. Вывод про молекулу ≠ вывод про рацион.

## Шесть классов нутриентов
| Класс | Энергия? | Количество |
|---|---|---|
| Углеводы | да | макро |
| Жиры | да | макро |
| Белки | да | макро |
| Витамины | нет | микро |
| Минералы | нет | микро |
| Вода | нет | много |

## Незаменимые нутриенты
- Организм **не делает сам** → только с едой
- Это: витамины, минералы, вода, электролиты, незаменимые аминокислоты, незаменимые жирные кислоты (линолевая, α-линоленовая)
- **9 незаменимых аминокислот:** гистидин, изолейцин, лейцин, лизин, метионин, фенилаланин, треонин, триптофан, валин
- Условно незаменимые — при болезни/стрессе

## Ценность: два разных понятия
- **Энергетическая** = сколько энергии («калории», метаболизируемая)
- **Пищевая** = состав по нутриентам
- «Калории» ≠ теплота сгорания: это энергия за вычетом потерь

## Этикетка
- **Размер порции** = сколько обычно едят, **не** рекомендация
- Частая ошибка: считать 1 порцию, а съесть 2–3 → **пересчитывай на фактический объём**
