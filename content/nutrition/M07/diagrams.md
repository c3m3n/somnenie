# M07 — Схемы

## Три типа пищевых волокон

| Тип | Основные источники | Механизм | Эффект |
|---|---|---|---|
| Растворимые / вязкие | Овсянка (β-глюкан), псиллиум, бобовые, яблоки, пектин | Образуют гель в кишечнике → замедляют всасывание | Гликемия ↓, LDL ↓, насыщение ↑ |
| Нерастворимые | Пшеничные отруби, цельные зерновые, овощи, орехи | Увеличивают объём содержимого кишечника | Стул ↑ объём, транзит ↑, запор ↓ |
| Ферментируемые (пребиотики) | Бобовые, лук, чеснок, цикорий, овёс, банан | Субстрат для кишечных бактерий → КЦЖК (бутират, ацетат, пропионат) | Микробиом ↑, воспаление ↓ → M15 |

> ⚠️ **Пребиотик ≠ вся клетчатка.** Пребиотик — только та клетчатка, которая избирательно ферментируется полезными бактериями. Целлюлоза ферментируется слабо — она нерастворимая, но не пребиотик.

## Расчёт нормы клетчатки и план набора

**Формула (Институт медицины США):**

```
Норма (г) = ккал в день ÷ 1000 × 14
```

| Калорийность | Цель клетчатки |
|---|---|
| 1 500 ккал | ~21 г |
| 1 800 ккал | ~25 г |
| 2 200 ккал | ~31 г |
| 2 700 ккал | ~38 г |

**Как набрать норму — конкретные источники:**

| Продукт | Порция | Клетчатка |
|---|---|---|
| Овсянка (сухая) | 40 г | +4 г |
| Чечевица варёная | 150 г | +8 г |
| Яблоко с кожурой | 1 шт (~180 г) | +4 г |
| Хлеб цельнозерновой | 2 ломтя (80 г) | +6 г |
| Овощи смешанные (брокколи, морковь) | 200 г | +5–8 г |

**План постепенного увеличения (чтобы избежать вздутия):**

```
Неделя 1: +5 г к текущему уровню
Неделя 2: ещё +5 г
...
Цель через 3–4 недели: выйти на норму
```

> ✓ Увеличивать клетчатку нужно вместе с водой — иначе эффект обратный (запор, тяжесть).

## Водный баланс: потребности, сигналы, мифы

**Ориентировочные суточные нормы (ВОЗ / EFSA):**

| Группа | Вода из всех источников (пища + напитки) |
|---|---|
| Женщины | ~2,0 л/день |
| Мужчины | ~2,5 л/день |
| Беременные | ~2,3 л/день |
| Кормящие | ~2,7 л/день |

**Сигналы гидратации:**

| Сигнал | Интерпретация |
|---|---|
| Цвет мочи — светло-жёлтый | 🟢 Норма |
| Цвет мочи — тёмно-жёлтый / янтарный | 🟡 Начинается дефицит → пей |
| Цвет мочи — коричневый | 🔴 Выраженное обезвоживание |
| Жажда | ⚠️ Уже лёгкий дефицит (~1–2% массы тела) |
| Мочеиспускание реже 3–4 раз/день | 🟡 Сигнал пить больше |

**Факторы, повышающие потребность:**

```
Жара / высокая температура воздуха  → ↑ потоотделение
Физическая нагрузка                 → ↑ потери с потом
Лихорадка                           → ↑ потери на испарение
Рвота / диарея                      → ↑ прямые потери
Большая высота над уровнем моря     → ↑ дыхательные потери
```

> ✗ **Миф: «детокс-вода» выводит токсины.** Детоксикацию круглосуточно выполняют почки и печень — независимо от содержимого стакана. Вода с лимоном, огурцом или углём не ускоряет этот процесс. Достаточная гидратация поддерживает работу органов — но это не «детокс».
