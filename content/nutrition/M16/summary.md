# M16 — Шпаргалка

## Оценка энергии
| Уравнение | Когда |
|---|---|
| Миффлина–Сан Жеора | по умолчанию для большинства |
| Харриса–Бенедикта | легаси, в среднем менее точно |
| Каннингема | известна тощая масса (сухие/мускулистые) |

- Миффлин (жен): 10×вес + 6,25×рост − 5×возраст − 161; (муж): +5 вместо −161
- **TDEE = обмен покоя × активность** — здесь главная ошибка (переоценка активности)
- Золотой стандарт измерения — непрямая калориметрия

## Цель
| Цель | Калории | Темп |
|---|---|---|
| Снижение жира | TDEE − умеренный дефицит | ≈0,5–1 кг/нед |
| Поддержание | ≈ TDEE | вес стабилен |
| Набор мышц | TDEE + **умеренный** профицит | медленно |

> Быстрый набор = больше жира, не больше мышц.

## БЖУ: сначала белок
1. **Белок** — 0,8 г/кг база; **1,4–2,0 г/кг** активным (ISSN)
2. **Жир** — 20–35% энергии
3. **Углеводы** — остаток (45–65%)
4. **Клетчатка** — 38/25 г (муж/жен)

## Петля коррекции
- Калькулятор = гипотеза, не закон
- Ранние сдвиги веса = вода + гликоген (**+3 г воды на 1 г гликогена**)
- Судить по **среднему тренду за 2–3 недели**, потом править калории/активность
