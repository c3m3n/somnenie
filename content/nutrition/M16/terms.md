# M16 — Термины

## Энергия

- ***Базовый / покоящийся обмен (BMR / RMR)*** — расход энергии в покое; основная часть суточного расхода.
- ***TDEE (суточный расход энергии)*** — полный суточный расход: обмен покоя × коэффициент активности (включает NEAT, тренировки, термический эффект пищи — см. M02).
- ***Непрямая калориметрия*** — наиболее точный метод измерения расхода энергии по газообмену; в быту недоступен.
- ***Прогнозное уравнение*** — формула оценки обмена покоя по полу, весу, росту, возрасту.
- ***Уравнение Миффлина–Сан Жеора*** — предпочтительная формула обмена покоя для большинства взрослых.
- ***Уравнение Каннингема*** — формула на основе тощей массы; точнее у мускулистых/сухих людей при известной безжировой массе.
- ***Тощая (безжировая) масса (FFM)*** — масса тела без жира; основной предиктор обмена покоя.

## Цели и макросы

- ***Энергетический дефицит / профицит*** — потребление ниже / выше расхода; основа снижения веса и набора массы.
- ***AMDR*** — допустимые диапазоны доли макронутриентов от энергии: углеводы 45–65%, жир 20–35%, белок 10–35%.
- ***RDA по белку (0,8 г/кг)*** — минимум для здорового взрослого; активным нужно больше.
- ***Норма белка для активных (1,4–2,0 г/кг/сут)*** — диапазон позиции ISSN.
- ***«Сначала белок»*** — порядок планирования БЖУ: задать белок и жир, углеводами добрать остаток энергии.

## Динамика

- ***Адаптация при похудении*** — снижение расхода энергии по мере уменьшения тела; причина «уезжающих» прогнозов.
- ***Гликоген и вода*** — каждый грамм гликогена запасается примерно с 3 г воды; объясняет быстрые ранние сдвиги веса.
- ***Тренд массы*** — среднее изменение веса за 2–3 недели; рабочий критерий прогресса вместо одного взвешивания.
- ***Петля коррекции*** — цикл «оценка → стабильный период → проверка тренда → правка»; важнее точности первой оценки.
