# M17 — Схемы

## Пирамида приоритетов при снижении веса

```
        [ДЕФИЦИТ ЭНЕРГИИ]          ← основа, без неё ничего не работает
       [БЕЛОК ≥1,6 г/кг]           ← сохранение мышц + насыщение
      [СИЛОВЫЕ ТРЕНИРОВКИ]         ← минимизация потери ФМТ
     [КАЧЕСТВО СНА + СТРЕСС]       ← гормоны голода и кортизол
    [РАСПРЕДЕЛЕНИЕ НУТРИЕНТОВ]     ← оптимизация, не основа
   [ТАЙМИНГ / ДОБАВКИ / "ЛАЙФХАКИ"] ← минимальный вклад
```

> Перевернули пирамиду? Пытаешься оптимизировать добавками при нарушенном сне — не сработает.

## Причины плато и решения

| Причина | Механизм | Решение |
|---|---|---|
| Метаболическая адаптация | RMR снизился на 5–15% | Пересчитать TDEE, уменьшить дефицит |
| Незамеченное увеличение порций | «Калорийная амнезия» | Временный трекинг (1–2 нед) |
| Снижение NEAT | Меньше двигаешься без осознания | ↑ шаги, стояние, бытовая активность |
| Стресс/недосып | ↑ грелин, ↑ кортизол | Нормализация сна, управление стрессом |
| Задержка воды | Тренировки, цикл, соль | Ждать 1–2 нед, смотреть тренд |
| «Диетный перерыв» | Намеренный период поддержания | 1–2 нед поддержания каждые 8–12 нед |

## Мифы о похудении: реальность vs маркетинг

| Миф | Реальность |
|---|---|
| «Ешь меньше 6 раз в день — ускоришь метаболизм» | Частота приёмов не влияет на TDEE |
| «Утренняя тренировка натощак сжигает жир» | Суточный дефицит определяет потерю жира, не время |
| «Детокс очищает организм» | Нет механизма, печень и почки справляются |
| «Без глютена = меньше калорий» | Безглютеновые продукты часто калорийнее |
| «Целлюлит лечится кремом» | Структура подкожной ткани, не загрязнение |
| «После 18:00 не есть» | Калории не считают время, важен суточный баланс |

## Поддержание веса: что говорит наука

```
Регистр NWCR (>10 000 чел. удерживают >14 кг более 1 года):
✓ Постоянный самомониторинг (вес, еда)
✓ Высокий уровень физической активности (~1 ч/сут умеренная)
✓ Завтрак ежедневно (у большинства)
✓ Ограничение TV-просмотра
✓ Последовательность в выходные = будни
```

> Удержание требует БОЛЬШЕ усилий, чем снижение — это нормально, а не провал.
